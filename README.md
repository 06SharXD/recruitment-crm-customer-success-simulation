# Recruitment CRM Customer Success Simulation

A portfolio project demonstrating a structured approach to customer support and customer success for a fictional recruitment CRM. All tickets, customers, conversations, and outcomes are synthetic and for demonstration only.

## Project focus

- Support-ticket triage, prioritisation, and escalation
- Customer communication and troubleshooting
- Recruitment-software onboarding resources
- FAQ and support operations playbook
- Mock customer conversations
- Support operations metrics and dashboard concepts

## Demo

Open [`demo/index.html`](demo/index.html) locally in a browser. If hosted through GitHub Pages, configure Pages to deploy from the `main` branch and use `/demo/` as the demo path.

## Repository structure

- `data/` — synthetic example support tickets in CSV and JSON formats
- `demo/` — local interactive dashboard
- `docs/` — onboarding guide, operations playbook, FAQ, resume bullets, and role alignment
- `conversations/` — mock customer conversations

## Important limitations

This is a simulation, not a production support system and not evidence of professional customer-support employment. The sample dataset does not represent real users or Recruit CRM internal data. Any metrics calculated from it must be described as simulated results.

## How to explore

1. Open the dashboard in `demo/index.html`.
2. Search and filter the example tickets.
3. Review the onboarding guide, troubleshooting FAQ, and operations playbook in `docs/`.
4. Use the mock conversations to practise explaining issues clearly, asking clarifying questions, and setting follow-up expectations.

## Skills demonstrated

Customer communication, support triage, issue documentation, escalation thinking, onboarding content design, and basic support-operations analysis.
