# Recruitment CRM Customer Success Simulation

A portfolio project demonstrating a structured approach to customer support and customer success for a fictional recruitment CRM. **All tickets, customers, conversations, and outcomes are synthetic.**

## Explore the project

- [Interactive dashboard source](demo/index.html) — open the file locally in a browser to use the searchable, filterable ticket explorer.
- [32 synthetic tickets (CSV)](data/synthetic_tickets.csv)
- [Synthetic ticket dataset (JSON)](data/synthetic_tickets.json)

## What this demonstrates

- Ticket triage, prioritisation, next-action tracking, and escalation logic
- Customer communication and troubleshooting scenarios
- Recruitment-software onboarding resources and user guidance
- A browser-based support operations dashboard with search, status/priority/category filters, and illustrative summary metrics
- Documentation of limitations and responsible handling of customer/candidate data

## Run the demo locally

1. Download or clone this repository.
2. Open `demo/index.html` in a modern browser.
3. Search by ticket, customer, category, or issue; filter by status, priority, or category.
4. Review the linked playbook, FAQ, onboarding guide, and mock conversations.

The dashboard embeds its synthetic data so it can run as a static page without installing dependencies or running a server.

## Important limitations

This is a learning simulation, not a production support system and not evidence of professional customer-support employment. It is not Recruit CRM software, is not affiliated with Recruit CRM, and does not use private Recruit CRM data. Metrics shown are illustrative and must not be represented as real business outcomes.
